放弃这个浏览器配置

放弃只会在本机数据库里把下面的待核查记录标为已确认，并把这个配置从列表里移除。它不会连接浏览器，不会重放、撤销或重新执行任何操作。

只在这个配置已经不存在时放弃：重建了配置 ID、卸载重装了扩展，或删除了这个 Chrome 配置。如果它只是暂时离线，请先关闭这个窗口，打开原来的 Chrome 继续连接，在原页面核查后再逐条解除保护。放弃之后，这些操作的实际结果不会再被核查，已经发出的操作也不会撤回；这个配置的配对也会作废，以后要用得重新配对。
    SaltedFish · 服务管理页浏览器保持你的登录状态。Agent 只能使用授权给它的 Chrome 配置；一次信任后，它在这些配置里的操作不再逐次确认。服务管理页和扩展自身页面受保护，Agent 不能读取或操作它们；Agent 只能从服务所在的电脑连接；上传和保存文件能用哪些路径由 Agent 自己的权限设置决定，SaltedFish 只拒绝它自己的数据目录和网络共享路径；浏览器下载导出使用可选本机助手。撤销只阻止之后的调用，已发出的操作不会撤回。
