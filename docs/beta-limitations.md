# 限制与数据说明

SaltedFish 让 Agent 使用已配对的日常 Chrome。它不是操作系统沙箱，也不保证所有网站和客户端组合都能完成任务。

## 平台与分发限制

- npm 包需要 Node.js 24+。Windows、Linux 已验证；macOS 分发未验证。
- 产品自身的安装器和启动器尚未签名，系统可能要求确认来源。文件完整性校验不等于发布者签名。
- Chrome 应用商店上架准备中。当前可用开发者模式加载扩展，手动加载的扩展需按[升级说明](npm.md#扩展更新)更新或重新加载。
- 不保证所有 Chrome 版本、系统缩放、休眠唤醒、网络切换及组织策略组合均可用。

## 页面与操作限制

- 网页能观察 DOM 和输入事件，不承诺无法识别自动化。Agent 光标画在 CDP Overlay，不往页面 DOM 或主世界添加提示；拟人输入用于兼容悬停、按住和拖拽时序，不构成识别保证。
- 不保证 Chrome 内部页、其他扩展页面、系统原生窗口、验证码或系统授权弹窗可操作。登录、验证码和权限提示可能需要手动完成。
- Chrome debugger 可能与 DevTools 或其他调试扩展冲突，部分 CDP 域和跨目标命令不可用。
- 视觉动作通常不切换当前标签页，但后台截图兜底可能短暂切到前台；最小化窗口会临时恢复。Agent 操作目标页时，手动改动仍可能影响结果。
- 工具完成不等于网站业务成功。已派发的点击、上传和网站请求无法保证撤回；撤销授权只能阻止后续请求。
- 断线、超时或崩溃可能留下结果不明。先检查真实页面和操作记录，再解除保护；不要整段重试。恢复步骤见[管理页指南](product-features.md#操作记录与结果不明恢复)。

## 连接与权限边界

`/mcp` 只接受服务所在电脑上的连接，其他电脑返回 HTTP 403 `MCP_LOCAL_ONLY`。Chrome 扩展可以在其他电脑连接服务。HTTP/WS 不加密，只适合可信内网；公网部署必须使用证书。

每个 Agent 使用独立凭据，并受浏览器范围、只读权限、受保护页面、租约和资源预算限制。一次信任不会取消这些限制，但允许 Agent 在授权配置中以已登录身份操作网站，含页面脚本和原始 CDP。详见[一次信任](once-trust.md)。

本机文件读写范围由 Agent 自己的权限或沙箱决定。SaltedFish 另行拒绝自己的数据目录、npm 安装数据根目录及网络共享路径。服务不会替 Agent 的 harness 建立操作系统级隔离；具有同一系统用户任意文件读写能力的程序仍在信任边界内。

普通 Agent 不能读取、操作服务管理页和扩展自身页面，也不能导航到它们。非管理员响应会隐藏 SaltedFish 数据目录路径，但下载位置等其他本机路径仍可能返回。浏览器配对不等于管理授权，恢复客户端审批也不等于撤销服务端凭据。

## 服务重启与会话

HTTP 入口可按原会话标识接回同一凭据的会话，但不保证客户端自行恢复。调用撞上服务停止时，可能需要手动重连；Claude Code 非交互 `-p` 会话尤其需要注意。HTTP 不会自动启动已停止的服务。

开过 GET 推送流的 HTTP 会话，在流断开且 2 分钟没有新请求后结束；从未开流的会话按 30 分钟空闲结束。标签组及占用随后释放。再次写入前可能需要 `chrome_claim_tab`；满足同一 Agent、同源且无其他占用等条件时才自动接回。

任务绑定提交时的浏览器连接，重连或重启不会自动重放未完成任务。标签组是协作边界，不是安全边界。

## 数据存放位置

npm 安装默认使用以下数据根目录：

- Windows：`%LOCALAPPDATA%/SaltedFish/npm`。
- Linux / macOS：`$XDG_DATA_HOME/saltedfish`；未设置时为主目录下依次为 `.local`、`share`、`saltedfish` 的目录。
- `SALTEDFISH_HOME` 或 `--home DIR` 可指定独立位置。

根目录下的 `versions` 保存运行快照，`logs` 保存管理日志；服务数据位于 `data/local`：

| 数据 | 内容与注意事项 |
| --- | --- |
| 配置与凭据 | 管理员凭据、客户端授权、浏览器配对信息；按私有资料保管 |
| SQLite 状态库 | 授权、操作记录、任务历史、流程定义及版本；服务重启保留结果不明保护 |
| `results` | 大 JSON、图片和可选故障截图，可能包含页面与表单内容 |
| `setup-backups` | 接入前客户端配置，可能含其他服务的凭据；最多 100 份 |
| `extension` | 手动加载的扩展文件和连接默认设置，不应公开分享本机目录 |

运行参数和任务脚本只在执行进程中使用，不从任务历史自动恢复。主动保存的流程定义例外，会持久保存；不要把密码、令牌或敏感文字写死在定义里。

操作审计不保存脚本、页面正文或上传文件内容。它保存工具、目标、时间和状态等元数据；上传还记录文件名、大小和文件摘要。任务名称、浏览器名称等是自行输入的内容，仍可能含敏感信息。

网络和控制台事件在有界内存缓存中保留，默认同时受 2000 条和 8 MiB 限制。结果文件默认总预算为 1 GiB，也有客户端额度；容量不足可能无法保存结果，但不应将已完成动作改判为未执行。历史未登记结果文件也计入容量，不自动删除。

## Chrome 保存的数据

浏览器身份、配对和扩展设置存放在 Chrome 扩展存储。更新原扩展保留这些内容；换加载目录或重装可能丢失，需用管理页“重新连接”恢复。

Agent 标签组由 Chrome 按普通标签组保存，可能包含组标题和组内网址。会话结束会解散组；退出 Chrome 时仍打开的组可能留下记录，需手动整理。是否同步到其他设备取决于 Chrome 账号和同步设置，不由 SaltedFish 控制。

## 数据传输与遥测

SaltedFish 不主动发送自己的遥测。它按配置连接浏览器、服务和客户端，并在安装或升级时访问包更新源。

Agent 调用返回的页面文字、截图、网络结果和文件内容会交给 Agent 客户端，并可能发送给该 Agent 所用的模型服务。后续处理受客户端、模型供应商和组织的数据规则管理。不要在无权向模型服务提供的页面上使用 Agent。

隐藏密码字段的结构化值，不代表页面文本、截图或原始网络数据全部脱敏。诊断导出虽不含运行参数、脚本和图片，分享前仍需检查路径、名称和环境信息。

进一步说明见[隐私政策](https://github.com/finmoor/saltedfish/blob/main/PRIVACY.md)和[安全说明](https://github.com/finmoor/saltedfish/blob/main/SECURITY.md)。

## 备份、撤销与卸载

备份前先停止服务，并妥善保管整个数据目录；备份可能包含长期凭据、页面结果和流程内容。升级与回滚只切换兼容程序，不恢复旧授权数据库，不复活已撤销凭据。

管理员密钥目前没有独立轮换命令。管理页使用有期限、可撤销的会话，但撤销会话不等于更换管理员密钥。怀疑长期密钥泄露时，需要重建私有配置，并重新配对浏览器和客户端。

卸载 CLI 不自动删除数据、快照、Chrome 扩展或客户端配置。`results remove` 永久删除选定结果；归档流程的永久删除也不可恢复。手动清理前核对目录归属，避免影响仍在使用的安装。操作步骤见[卸载指南](npm.md#卸载)。
